Swing Net V2

골프 스윙 중 8가지 자세를 감지하고 Joint Angle Point를 정량화하는 End-to-End AI 모델. CNN+LSTM 하이브리드 구조를 ConvLSTM으로 교체하여 시공간 특징을 동시에 학습합니다.

기간2025.04.28 — 06.18 (8주)
역할머신러닝 기술 리드
팀 구성3인 팀 (60% 기여)
주관고려대학교 지능정보SW아카데미

Overview

CVPR Golf DB 논문 (McNally et al., 2019)을 기반으로, 비디오 데이터의 공간 정보와 시계열 특성을 동시에 학습하기 위해 ConvLSTM 구조를 채택했습니다.

기존 CNN+LSTM 하이브리드 모델을 대체하여 데이터 EDA → 증강 → 전처리 → 학습 → 검증 → 평가까지 Vision AI 학습의 전 과정 파이프라인을 직접 구현했습니다.

MediaPipe를 활용한 HPE(Human Pose Estimation) 결과 시각화를 통해 모델 품질을 정성적으로 평가할 수 있는 시스템을 구축했습니다.

Role & Work

1 키포인트 어노테이션 수행 — CVAT를 활용하여 골프 스윙 영상에서 신체 관절 포인트를 직접 레이블링
2 Augmentation 적용 및 이미지 포맷 전처리 — Albumentations 기반 다양한 증강 기법 적용으로 데이터 다양성 확보
3 다양한 BackBone 모델 실험 — MobileNetV2, EfficientNetV2, SqueezeNet, MobileNetV4, ConvLSTM 비교 분석 및 성능·경량화 Trade-off 분석을 통해 최종 모델 선정
4 Pytorch.Profiler 활용 병목 분석 — CPU/GPU 부하 분석 및 병목구간 개선으로 Latency 16% 단축
5 하이퍼파라미터 파인튜닝 — BatchSize, EarlyStopping, GradientAccumulation, LRScheduler, Warm-up 최적화
6 HPE 시각화 구현 — PIL 기반 결과 이미지 변환 및 포즈 추정 결과를 시각적으로 확인 가능한 파이프라인 구축

배운 점 & 회고

비디오 데이터의 공간 정보와 시계열적 특성을 동시에 학습하기 위해 ConvLSTM 구조를 채택하는 과정에서, 단순히 성능 지표를 높이는 것을 넘어 모델 선택의 근거와 Trade-off를 깊이 이해하게 되었습니다.

팀원과 CNN 스터디를 진행하며 눈높이에 맞춰 기술을 설명하는 역량을 키웠습니다. 논문과 GitHub에 명시되지 않은 데이터 검증 기준을 직접 객관화한 경험은, 프로젝트의 본질을 파악하고 비판적으로 접근하는 중요성을 다시 한번 일깨워 주었습니다.
